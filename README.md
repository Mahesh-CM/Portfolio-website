# Portfolio Website

A responsive, single-page personal portfolio built with plain HTML and CSS. It presents my background, skills, experience, projects and education as an MCA student preparing for entry-level software and data roles.

## Sections

- **Home**: introduction and quick links
- **About**: education summary and interests
- **Technical Skills**: languages, databases, tools and machine learning libraries
- **Experience**: data analyst internship
- **Projects**: Mastitis Disease Detection, Company Visitor Management System, Customer Segmentation and Sales Analysis
- **Education**: MCA, BCA, PUC and SSLC
- **Activities and Certifications**
- **Contact**: contact form layout and links

## Tech stack

- HTML5 (semantic sections)
- CSS3 (flexbox and grid layouts, responsive breakpoints, mobile hamburger menu using a CSS-only checkbox toggle)
- Google Fonts (Inter, Poppins)
- Font Awesome icons via CDN

No build step, framework or JavaScript is required.

## Project structure

```
index.html    page markup
style.css     all styles
profile.jpg   profile photo
GUIDE.md      setup and hosting notes
```

## Run locally

1. Clone or download this repository.
2. Open `index.html` in any browser.
3. Resize the window to check the mobile layout.

## Deploy

The site is static, so it can be hosted for free on GitHub Pages, Netlify or Vercel. For GitHub Pages: repository **Settings → Pages → Deploy from a branch → `main` / root**. See `GUIDE.md` for details.

## Notes

The contact form is a front-end layout only and does not send messages yet. Connecting it to a service such as Formspree is a possible next step.
